# 📡 GeoChat — клиент-серверный чат с геолокацией

Простой TCP-чат на Python: клиент автоматически отправляет свой **публичный IP** и **геолокацию**, сервер принимает подключения и показывает, откуда ты вышел на связь.

## ⚙️ Как это работает

```
┌──────────────┐         TCP          ┌──────────────┐
│   КЛИЕНТ     │  ───────────────▶    │    СЕРВЕР    │
│  (ПК2, ноут) │                      │   (ПК1)      │
│              │  1. IP + гео         │              │
│  socket ─────┼─────────────────────▶│  принт IP    │
│              │  2. сообщения        │  принт msg   │
│              │◀─────────────────────│              │
└──────────────┘                      └──────────────┘
```

1. Клиент запускается → делает запрос на `api.ipify.org` (получить IP) и `ip-api.com` (получить город/страну/координаты).
2. Клиент подключается к серверу по TCP.
3. **Первым сообщением** всегда идёт строка вида:
   ```
   IP=89.113.xx.xx | Moscow, Russia | 55.75,37.61
   ```
4. Сервер печатает эти данные → ты видишь, откуда подключился клиент.
5. Дальше идёт обычный чат: всё, что пишешь — уходит на сервер.

## 💻 Быстрый старт (локальная сеть)

> Подходит, если ПК1 (сервер) и ПК2 (клиент) в **одной Wi-Fi сети** (например, дома).

**На ПК1 (сервер):**

```bash
# Узнай локальный IP: ipconfig (Windows) / ifconfig (Linux/macOS)
# Допустим: 192.168.1.130
python server.py
```

Увидишь:

```
[+] Сервер запущен на порту 5000. Ждём подключений...
```

**На ПК2 (клиент):**

Открой `client.py`, убедись что:

```python
HOST = '192.168.1.130'   # локальный IP ПК1
PORT = 5000
```

Запусти:

```bash
python client.py
```

На сервере появится:

```
[+] Подключился: 192.168.1.55:54321
[i] Данные клиента: IP=89.113.xx.xx | Moscow, Russia | 55.75,37.61
```

## 🌐 Доступ из любой точки мира

Когда ты уходишь с ПК2 в город (мобильный интернет), локальный адрес `192.168.1.130` **не работает**. Нужно "пробросить" сервер наружу. Три способа:

### Вариант 1. ngrok (рекомендуется)

Самый быстрый — 5 минут, без настройки роутера, работает даже за CGNAT.

```bash
# 1. Скачай ngrok: https://ngrok.com/download
# 2. Зарегистрируйся и получи токен
ngrok config add-authtoken ТВОЙ_ТОКЕН

# 3. Запусти свой сервер
python server.py

# 4. В новом окне терминала
ngrok tcp 5000
```

ngrok выдаст:

```
Forwarding  tcp://0.tcp.ngrok.io:12345 -> localhost:5000
```

Теперь в `client.py` на ПК2 меняешь:

```python
HOST = '0.tcp.ngrok.io'
PORT = 12345              # порт из вывода ngrok
```

Готово. Идёшь в кафе в центре города → запускаешь → на ПК1 видишь свой город и IP.

> 🔵 Альтернатива без регистрации: cloudflared
> ```bash
> cloudflared tunnel --url tcp://localhost:5000
> ```

---

### Вариант 2. Проброс порта на роутере

1. Заходи в админку роутера → `192.168.1.1`
2. Найди **Port Forwarding / Виртуальные серверы**
3. Правило: внешний порт `5000` → `192.168.1.130:5000`
4. Узнай публичный IP:
   ```bash
   curl ifconfig.me
   ```
5. В `client.py`:
   ```python
   HOST = '89.113.xx.xx'   # твой публичный IP
   PORT = 5000
   ```

⚠️ **Минусы:**
- IP динамический → нужен DDNS (например, noip.com)
- Если у провайдера **CGNAT** — ничего не выйдет, используй ngrok

---

### Вариант 3. VPS с белым IP

Самый надёжный. Арендуешь VPS (~150₽/мес), поднимаешь сервер там, оба ПК подключаются как клиенты.

Плюсы:
- Стабильный IP
- Работает всегда
- Можно расширить до полноценного сервера с БД, авторизацией и т.д.

## 🐛 Частые проблемы

| Ошибка | Причина | Решение |
|---|---|---|
| `ConnectionRefusedError` | Сервер не запущен / неверный порт | Проверь, что `server.py` работает и порт совпадает |
| `TimeoutError` при `api.ipify.org` | Нет интернета / блокировка | Проверь сеть, попробуй VPN |
| Не подключается из города | Используется локальный `192.168.x.x` | Настрой ngrok / проброс порта |
| Гео показывает `unknown` | Не удалось получить IP | Проверь доступ к `ip-api.com` |
| `Address already in use` | Порт занят | Убей старый процесс или смени `PORT` |

## 🔒 Безопасность

⚠️ **Это учебный проект. Не используй его в продакшене как есть.**

Что стоит добавить:

- 🔑 **Аутентификацию** — сейчас любой может подключиться
- 🔐 **Шифрование** — данные идут в открытом виде по TCP
- 🌐 **TLS/SSL** — оберни сокет в `ssl.wrap_socket` или используй SSH-туннель
- 📝 **Логирование** — писать подключения в файл
- 🚫 **Rate limiting** — защита от спама
- 👥 **Мультиклиентность** — сейчас сервер обрабатывает по одному клиенту

Для публичного сервера:
- ngrok туннель лучше закрыть паролем
- Логировать **все** подключения
- Не публиковать свой реальный IP без необходимости
